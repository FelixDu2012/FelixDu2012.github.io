## 后续修复：加载速度优化（用户反馈 3 分钟加载不出）

- **根因**：字体全部 base64 塞进 index.html，单文件 2.4MB，浏览器必须下完才渲染；叠加 GitHub Pages 国内访问慢
- **修复**：字体改为 `assets/fonts/*.woff2` 独立文件引用（font-display:swap + preload），皮肤图也改为文件引用 + lazy
- **结果**：index.html 2.4MB → 50KB（-98%），DOM 加载 170ms；签名/Minecraft logo 仍保持 base64（仅约 27KB，可忽略）
- 验证：本地 playwright 字体 loaded、无失败请求；线上主页 50KB/0.8s、字体/皮肤均 200
